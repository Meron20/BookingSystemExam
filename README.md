# Booking System – individual coding exam

A console application for managing meeting room bookings. The application
targets .NET 10 and contains a console application and xUnit tests.

## Requirements

- .NET 10 SDK

## Run the application

**In the terminal:**

```bash
dotnet run --project src/BookingSystem
```

**In Visual Studio:** open the solution, set `BookingSystem` as the startup
project and press F5 (or the green ▶ button).

## Run the tests

**In the terminal:**

```bash
dotnet test
```

**In Visual Studio:** Test > Test Explorer > Run All.
